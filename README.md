Question 2: HTML Elements
1. Five challenging elements
The five elements I found most challenging were:
`<form>` — It required several related controls and attributes to create an organized contact form.
`<table>` — I had to understand how the table, rows, headings, and data cells work together.
`<figure>` — I used it together with `<img>` and `<figcaption>` so that the image had a meaningful description.
`<details>` — This provides expandable content using HTML without JavaScript.
`<progress>` — I needed to understand how the `value` and `max` attributes represent progress.
2. Semantic HTML structure
I used semantic elements such as `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>`. These elements describe the purpose of different parts of the page and make the document easier to understand and maintain.
3. Most useful layout element
The `<section>` element was particularly useful because it allowed me to divide the website into clear areas such as About Me, Skills, Projects, Education, and Contact.
Question 3: HTML Attributes
1. Three essential attributes
Three important attributes were:
`href` — Makes navigation and links functional.
`src` — Tells the browser where an image should be loaded from.
`action` — Defines where form data is submitted.
2. Class and id
An `id` identifies one specific element on a page and can be used for links such as `href="#about"`. A `class` can be assigned to multiple elements when they need to share a classification or styling rule. This assignment mainly demonstrates the `id` concept for navigation.
3. Attribute that improved user experience
The `alt` attribute improved user experience the most because it provides alternative text describing an image. This is useful when an image cannot load and also helps accessibility.
